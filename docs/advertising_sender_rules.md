# 広告送信者ルール

## 目的

Thunderbirdの送信者アドレス完全一致フィルタをWIBへ移し、広告メールを`一括処理`・スターなしへ自動整理する。

## データと判定

- 正本はWIBのSQLite `advertising_senders`。
- `From`から抽出して小文字化したメールアドレスの完全一致で判定する。
- 表示名は参考情報として保存するが判定には使わない。
- 一致したメールは既存タグを維持し、`wib-bulk`を追加してスターを外す。
- 過去メール全体への自動遡及は行わない。

## 接続できない場合の登録

Extensionの「この送信者を広告として登録」は、表示中メールへ一時タグ`wib-ad-sender-register`（広告送信者登録）を付ける。これは作業分類ではなく、IMAPを介した登録依頼キューである。

通常同期は未読状態、チェックポイント、`new_mail_lookback_days`とは別にこのタグを検索する。次の順で処理する。

1. `From`アドレスを正規化してSQLiteへ登録する。
2. メールへ`wib-bulk`を付ける。
3. スターを外す。
4. 成功後に`wib-ad-sender-register`を外す。

失敗時は依頼タグを残し、次回同期で再試行する。重複登録は成功として扱う。

## 管理UI

Extensionダッシュボードの「広告送信者を管理」から専用画面を開く。WIB接続中は一覧、手入力追加、削除を利用できる。WIB未接続時はDB操作を無効にするが、メール閲覧画面からの依頼タグ付与は利用できる。
