# WorkInBox 設計書

## 目的

WorkInBox は、メールやコミュニケーションツールから発生する仕事を整理し、
現在抱えている仕事を見える化するためのツールである。

WorkInBox はタスク管理ツールではない。

利用者に新たなタスク入力を要求せず、
既に存在する仕事を整理することを目的とする。

---

## 設計原則

### 1. 手動でタスクを登録しない

利用者は新たなタスク入力を行わない。

既存のメールや通知を利用する。

### 2. 現在の運用を変更しない

利用者のワークフローをできるだけ変更しない。

現在想定している運用は以下の通り。

- 未読メールを確認する
- 対応が必要なメールにスターを付ける
- 不要なメールはアーカイブする
- 作業完了後にスターを外す

### 3. 元メッセージを正本とする

WorkInBox は仕事のコピーを管理する。

メールやメッセージそのものを管理対象にはしない。

### 4. AIは整理役である

AIは以下を支援する。

- 分類
- 要約
- 締切抽出

最終的な判断は利用者が行う。
